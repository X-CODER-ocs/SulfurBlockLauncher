SulfurBlockLauncher

硫磺方块启动器 —— 一款开源、跨平台的 Minecraft 启动器与实例管理器

同时支持 Java 版与基岩版，覆盖 Windows / Linux / macOS

⬇ 下载最新版 在 GitHub 查看源码

核心功能

少一点配置，多一点游戏。从安装、登录到资源管理与联机，一站式搞定。

🗂️
标签页式导航

清晰的多标签页界面，游戏、下载、账户、存档分区管理，操作一气呵成。

🟩
Java 版 / 基岩版

同时支持 Java 版与基岩版启动管理，原版、加载器与游戏本体一键安装。

📦
下载管理

Java、MCJE、模组等资源统一下载与管理，文件自动归入对应目录。

👤
账户管理

支持正版、离线、外置登录等多种账户类型，切换账户轻松自如。

💾
存档管理

存档备份、编辑与管理，珍贵世界不再因误操作而丢失。

🔗
联机功能

内置陶瓦联机、硫磺联机，和朋友一起开黑就是这么简单。
