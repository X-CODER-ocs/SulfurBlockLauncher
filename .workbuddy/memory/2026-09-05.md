## 构建 Mac 版 Portal（正式可发布）
- 工具链：x64 .NET 10.0.400 SDK 于 Rosetta 2（~/dotnet11x64），macOS 27 上 arm64 原生 .NET 仍报 0x8007000C（CoreCLR 初始化失败，微软无补丁）。
- 命令：`dotnet publish src/Portal.Desktop/Portal.Desktop.csproj -r osx-x64 -c Release --self-contained true`（用全局 default dotnet 即 ~/dotnet11x64）。
- 结果：0 错误，自包含包（x86_64 apphost + 捆绑的 libcoreclr/libhostfxr/System.Private.CoreLib）。
- DotNet.Bundle 未自动出 .app，需手搓：copy publish→Contents/MacOS（剔除 .pdb）、assets/Icon-Pattern-Shadow-Border.icns→Contents/Resources、写 Info.plist。
- 签名关键顺序（否则失败）：① 递归 ad-hoc 签名 MacOS 内**所有文件**（含 .json/.config，否则签 apphost 时报 "In subcomponent: runtimeconfig.json"）→ ② apphost 带 allow-jit 授权重签（`codesign --force --sign - --entitlements /tmp/ent_allowjit.plist .../Portal.Desktop`）→ ③ 密封 bundle（`codesign --force --sign - .../Portal.Desktop.app`）。
- 授权 plist 路径 /tmp/ent_allowjit.plist（含 allow-jit / allow-dyld-environment-variables / debugger / disable-library-validation / get-task-allow）。
- 验证：实跑 apphost，CoreCLR 正常初始化、窗口显示完成、配置落盘 /Users/cangcang/Library/Application Support/cc.tiouo.Portal，无 0x8007000C。

## 产物
- `.app`：`src/Portal.Desktop/bin/Release/net10.0/osx-x64/Portal.Desktop.app`（134M，自包含，双击即可在 Mac 打开；Rosetta 转译）。
- 启动：`open .../Portal.Desktop.app` 或 `./.../Portal.Desktop.app/Contents/MacOS/Portal.Desktop`。
